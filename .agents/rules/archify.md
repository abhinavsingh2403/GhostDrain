## Archify Diagramming

Use Archify when generating technical architecture diagrams, system flows, API call chains, state machines, or data pipelines.
- Generate valid typed intermediate representation (IR) JSON based on Archify schemas.
- Use `archify finalize <type> <candidate.json> <output.html> --quality showcase --json` or `archify render` to validate and compile interactive standalone HTML diagrams with dark/light themes and export options.
- CLI command `archify` is globally installed and executable.
